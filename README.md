# SynologySStoTelegram
English version: [README_EN.md](README_EN.md)

Уведомления из Synology Surveillance Station: движение, лица, номера, AI-события, снимки и видео приходят в **Telegram**, **VK**, **MAX**, **MQTT**, **Web Push** и во внешние **вебхуки**. Работает со всеми версиями Surveillance Station, включая 9.3+, где Synology удалила часть API: режим определяется автоматически.

## Возможности
- **Мессенджеры:** Telegram (в том числе через VPN WireGuard / AmneziaWG и VLESS), VK, MAX; отдельные очереди доставки с повторами.
- **Другие каналы:** MQTT (в т. ч. для Home Assistant), Web Push, внешние вебхуки, внешний API с документацией (Swagger).
- **Форматы уведомлений:** фото + видео по запросу, полное видео, видео кусками; настраиваемый шаблон текста с предпросмотром.
- **Дашборд:** последние движения с превью и видео, сводка за 24 часа (график по часам, здоровье доставки, шумные камеры), закреплённые события, «Почему не пришло?».
- **Камеры:** статус онлайн/офлайн, снимок «сейчас», правила движения, расписание уведомлений по камерам и режиму «Дома».
- **Управление через бота:** команда `/menu`, дайджест активности с диаграммой.
- **Надёжность:** сторож системы (воркеры, диск, доступность Synology), автокопии настроек, страница «Здоровье» с хранилищем, журнал событий.
- **Совместимость:** автоопределение API Synology (SS 8.x, 9.x), диагностика совместимости, 2FA с device token, HTTPS.
- **Безопасность:** вход с ограничением попыток, права по разделам, защита AJAX от CSRF, экспорт/импорт настроек без секретов.
- **Remote-режим:** портал и мост между несколькими инсталляциями.
- **Интерфейс:** светлая/тёмная тема, русский и английский, мобильная версия, установка как PWA.

## Установка через docker-compose
Конфиг:
```yml
version: '3.8'
services:
    php:
        image: striker72rus/video-ss-to-tg-php:latest
        hostname: php
        restart: unless-stopped
        volumes:
            - '/PATH_TO_DATA:/usr/src/app/data'
        ports:
            - '8888:80'
            - '18081:18081' #Нужен для обновления дашборда в режиме реального времени.
```

## Настройка Telegram

Для добавления чатов сделан автоматический механизм, чтобы пользователь не задумывался с верными указанием ID.
1) Необходимо добавить своего бота в нужные чаты, группы.
2) Затем нажать на кнопку Автодобавление чата.
![](./images/14.0.png)
3) Проект начнёт ожидать команду <code>/chat</code> её необходимо отправить во все интересующие чаты/топики. Бот сам определит их и добавит в список
![](./images/14.png)
4) Когда все чаты/топики добавлены, можно остановить ожидание, нажав соответствующую клавишу.
5) Бот сам определяет название чата/топика, но если не смог или Вам неудобно - всегда можно переименовать для удобства.
6) Каждый чат/топик можно проверить нажав на клавишу тест, бот отрпавит туда тестовое сообщение.

## Настройка камер
При первом запуске необходимо нажать "обновить список" чтобы получить список камер.

После обновления они появятся в интерфейсе.<br>
Поддерживаются только камеры, которые записывают 24/7 или запись по событию. **Гибридная система не поддерживается.**

![](./images/ui-cameras.png)

 Отсюда можно создать правило перехвата событий кнопкой "Создать правило"<br>
 После нажатия появится окно с настройкой, его можно будет вызвать и позже по кнопке "Настроить":

![](./images/9.png)

Здесь можно настроить как будут приходить оповещения:
- **Фото + видео по запросу** - как только прилетает хук, система делает снимок с камеры и присылает его, добавляя кнопку "запросить видео"
- **Полное видео** - система ждёт когда закончится ивент и отправит полное видео.
- **Видео кусками** - Система будет отсылать видеофрагмент N-секундными интервалами, до тех пор, пока ивент есть.

Так же есть возможность управлять настройками через бота.
Вызов через команду 
```
/menu
````

![](./images/13.1.png)

Выбираете нужную камеру и настраиваете по своему вкусу:

![](./images/13.2.png)

В меню (Telegram и MAX) доступно:
- **Состояние** уведомлений и сводка за 24 часа в заголовке.
- **⏸ Пауза** на 1, 3, 8, 24 часа или до утра и **▶️ Включить**.
- **📊 Сводка** за сутки, **🩺 Здоровье** (процессы и свободное место), **🔁 Повторить ошибки** доставки.
- В меню камеры: статус (онлайн, запись), **📸 Снимок** сейчас, **🕘 События** (последние за сутки с запросом видео) и **🔕 Тишина** на 1, 8 или 24 часа.
- Параметры нарезки видео показываются только при включённом режиме «Нарезка видео».

## Как обновить проект

Обновить проект можно очень просто в интерфейсе.
Зайдите во вкладку "обновление"
Если будет доступно обновление - появится кнопка "Обновить до последней версии".

Тут же можно увидеть краткую сводку что изменилось.

![](./images/11.png)

После запуска процесса обновления, система сама всё скачает и установит.
Время обновление может занять от 1 до 5 минут, в зависимости от скорости Вашего интернета.

## Логи
Раздел «Прочее → Логи» помогает разобраться, что происходило в системе.

![](./images/ui-logs.png)

- Файлы логов выбираются по датам; рядом с каждым файлом видно число критических ошибок (CRIT), ошибок (ERR) и предупреждений (WARN).
- Внутри файла работают поиск по тексту и режим «следить за хвостом» (новые строки появляются сами).
- Вкладка «Логи обновления» показывает журнал последнего обновления приложения.
- «Скачать логи за дату (ZIP)» собирает архив за выбранный день, «Отправить в поддержку» открывает Telegram-бота поддержки, чтобы отправить выбранный лог разработчику.
- Сторонние логи (например, отчёт сервера) можно загрузить файлом или ZIP-архивом — они появятся в списке ниже.
- Старые даты можно удалить кнопкой с корзиной (с подтверждением). Токены и пароли в логи не попадают.

## Пользователи
Раздел «Пользователи» доступен только владельцу (суперадмину).

![](./images/ui-users.png)

- **Добавить** — создать учётную запись (email и пароль) и выбрать разделы, к которым у неё есть доступ: дашборд, настройки, камеры, документация, логи, обновление, пользователи.
- **Изменить** — поменять права и статус (активен или заблокирован).
- **Сбросить пароль** — задать новый пароль; при входе пользователю предложат сменить его (колонка «Требуется смена пароля»).
- **Удалить** — удалить учётную запись (с подтверждением).
- Вход защищён ограничением числа попыток и защитой форм от подделки запросов.
